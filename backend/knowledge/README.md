# Knowledge folder (SOPs and contacts for the assistant)

Put your site's safety procedures (SOPs) and contact lists here as `.md` or `.txt` files.
The assistant answers questions like "What is the fire procedure for Block B?" only from these files.

- One topic per file is easiest to maintain (e.g. `fire-procedure.md`, `contacts.md`).
- Use `#` headings: each paragraph keeps its heading, which helps the search.
- Changes are picked up automatically on the next question; no restart needed.
- This README is ignored by the search.

`SAMPLE-sop.md` is an invented example so the feature can be demonstrated. Replace it with real SOPs
before showing it as real, or say on stage that it is sample content.
